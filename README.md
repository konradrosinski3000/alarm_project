Projekt przedstawia system alarmowy bazujacy na 
mikrokontrolerze Arduino Uno R3. System monitoruje przestrzen
za pomoca trzech czujnikow ruchu PIR i w momencie wykrycia ruchu
alarmuje to dzwiekowo. System jest kontrolowany z poziomu wyswietlacza
zapewniajac prosty w obsludze interfejs sterowany trzema przyciskami 
i pokazujacy opcje na wyswietlaczu. System zaprogramowany jest w srodowisku 
Arduino w jezyku C.
